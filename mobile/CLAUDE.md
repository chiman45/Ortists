# Ortists Mobile (Flutter)

Before doing anything in this folder:
1. Read `PRD.md` (what to build and the rules).
2. Read `PROGRESS.md`, then continue with the first unchecked task whose dependencies are done.
3. After finishing a task: run `flutter analyze` and `flutter test`, tick the task, and add a Log line in `PROGRESS.md`.

The backend is the Next.js app in the repo root (`../src/app/api`). Read the matching `route.ts` before writing any model or API call.
